**生效日期：2026 年 8 月 28 日**

北京暗线科技有限公司（以下简称「我们」）重视您的个人信息与隐私保护。本隐私政策说明您在 **Coutto 纽扣纸样** 移动应用（以下简称「服务」）中，我们如何收集、使用、存储、共享和保护您的个人信息。

请您在使用服务前仔细阅读本政策。开始使用或继续使用服务，即表示您已理解并同意本政策。

## 1. 适用范围

本政策适用于 **Coutto 纽扣纸样** 移动应用及其相关服务，包括纸样投影、裁切、拼接、打印、管理与存储等功能。若服务内另有单独隐私说明，该说明与本政策不一致的，以单独说明为准。

## 2. 我们收集的信息

我们遵循合法、正当、必要和诚信原则，仅收集实现产品功能所必需的信息。

### 2.1 您主动提供的信息

- **联系信息**：当您通过邮件或表单联系我们时，可能提供邮箱地址、姓名及沟通内容
- **账号与资料信息**：当您登录或注册时，可能提供手机号码（仅在您使用手机号登录时，该方式目前仅适用于 Android）、第三方账号标识（微信或通过 Apple 登录），以及您填写的昵称、头像等资料；邀请码（选填）用于领取存储奖励。iOS 版支持通过 Apple 登录，在中国地区也可使用微信登录。
- **用户内容**：您导入、创建或管理的纸样文件、图片、项目记录等（主要在您的设备本地处理与存储）

### 2.2 自动收集的信息

为保障服务稳定运行、改进产品体验，我们可能收集：

| 信息类型 | 典型内容 | 主要用途 |
| --- | --- | --- |
| 设备信息 | 设备型号、操作系统版本、语言、屏幕参数、**Android ID（Android_ID）**、OAID、IMEI、MEID、IMSI、GUID、设备序列号、**设备 MAC 地址**、SIM 卡序列号（ICCID） | 识别设备、云备份设备归属、保障服务安全与运行质量、统计分析与反作弊 |
| 软件安装列表 | **已安装应用信息**（包括是否安装微信、抖音等）或运行中的进程信息 | 判断是否可以使用微信登录或打开抖音内容；统计分析与安全保障 |
| 应用信息 | App 版本、安装渠道、功能使用情况 | 产品改进、故障诊断 |
| 日志信息 | 错误日志、性能数据（按平台） | 提升稳定性与安全性 |
| 网络信息 | IP 地址（脱敏或近似位置）、网络类型 | 安全防护、统计分析 |

因操作系统不同，Android 与 iOS 收集的信息有所差异，详见第 2.2.1 节与第 2.2.2 节。

此外，即使用户不登录，服务也会生成匿名用户标识，用于云端纸样库、云备份、积分等功能（详见第 4 节）。该标识本身不直接识别您的身份。

#### 2.2.1 Android 设备标识、MAC 地址与软件安装列表

为识别设备、防范恶意程序与作弊、保障账号与云备份安全，以及保障服务运行质量与效率，**Android 端**会收集设备标识信息，包括 **IMEI、设备序列号、OAID、MEID、Android ID（Android_ID）、IMSI、GUID、MAC 地址、SIM 卡序列号**。同时可能获取已安装应用信息（**软件安装列表**）或运行中的进程信息。

- **目的**：识别本机以便云备份归属校验；判断是否已安装微信、抖音等应用以便登录或打开内容；开展应用统计、崩溃监控与基础反作弊；保障服务安全与运行质量。
- **方式**：由本应用及合作的统计分析、登录服务在设备上收集（详见第 4.1 节）。
- **范围**：仅限 Android；仅用于本条及第 3、第 4 节所述目的，不用于向您投放广告，也不会出售给无关第三方。iOS 版不收集上述 Android 设备标识、MAC 地址与已安装应用信息。

其中 **Android ID（Android_ID）** 由本应用读取，用于识别云备份所属设备；**设备 MAC 地址**、部分设备标识及 **已安装应用信息** 主要由统计分析服务、微信登录服务收集（详见第 4.1 节）。

#### 2.2.2 iOS 版收集的信息

iOS 版不收集第 2.2.1 节所述的 Android 设备标识、MAC 地址与已安装应用信息。当您使用 iOS 版时，我们可能收集以下信息，用于提供服务、保障安全与改进体验。这些信息可能与您的账号或设备相关联，但我们不会将其用于跟踪您在其他公司应用中的活动，也不会用于向您投放第三方广告。

| 信息类型 | 是否收集 | 用途 | 说明 |
| --- | --- | --- | --- |
| 电子邮件地址 | 是 | 提供服务 | 您使用通过 Apple 登录并选择分享邮箱时；您领取内测会员资格时填写的邮箱；您发邮件联系我们时 |
| 姓名 | 是 | 提供服务 | 您在资料中填写的昵称与简介（对其他用户可见，仅您本人可修改）；您使用通过 Apple 登录并选择分享姓名时 |
| 电话号码 | 否 | — | iOS 版不提供手机号登录，我们不收集您的电话号码 |
| 用户内容 | 是 | 提供服务 | 您导入或创建的纸样与刺绣文件、标签、文件夹；您开启云备份时，相关内容会同步到我们的服务器 |
| 照片或视频 | 是 | 提供服务 | 您上传的头像；您使用相机扫描纸样或校准投影时，影像主要在本机处理 |
| 用户 ID | 是 | 提供服务 | 用于登录、订阅、积分与云备份的账号标识，以及通过 Apple 登录时由 Apple 提供的账号标识 |
| 设备 ID | 是 | 提供服务、统计分析 | 用于区分设备、统计使用情况并防范滥用。我们不会获取用于广告跟踪的设备标识，也不会将设备标识用于广告投放 |
| 购买项目 | 是 | 提供服务 | 您通过 App Store 购买的订阅与积分记录及相应权益。我们不收集您的银行卡号或支付密码 |
| 产品交互（使用数据） | 是 | 统计分析 | 您使用应用的时长、浏览的页面与功能使用情况，用于了解产品表现并改进服务 |
| 崩溃数据、性能数据 | 是 | 提供服务、改进体验 | 应用发生故障或运行异常时的诊断信息，用于修复问题、提升稳定性 |
| 广告数据 | 否 | — | 我们不会将您的信息用于广告投放或跨应用跟踪 |

**通过 Apple 登录：** 当您选择该方式时，我们会接收 Apple 提供的账号标识，以及您选择向我们分享的姓名和邮箱，用于创建或登录您的账号。相关登录凭证仅用于完成登录，不会在您的设备上长期保存。为在您删除账号时解除与 Apple 的关联，我们会在服务器上保存完成该操作所需的授权信息，且仅用于此目的；账号删除后，上述信息将被撤销并删除。

### 2.3 权限相关信息

为实现特定功能，App 可能在获得您的授权后访问：

- **相册 / 文件**：导入、导出、保存纸样或项目文件
- **相机**：扫描或拍摄纸样相关内容
- **网络**：检查更新、同步或加载必要资源

您可在系统设置中关闭相关权限；关闭后，部分功能可能无法使用，但不影响其他基础功能。

## 4. 信息共享与披露

我们不会出售您的个人信息。仅在以下情形中共享：

- **经您明确同意**
- **履行法定义务**：应法律法规、司法或行政机关要求
- **服务提供商**：为实现必要功能，我们可能与以下第三方合作，并要求其遵守保密义务（具体收集项见第 4.1 节）：
  - **RevenueCat**：处理订阅与积分购买状态、权益信息及匿名用户标识，用于内购与权益发放
  - **阿里云**：提供账号体系、云端纸样库与云备份的服务器托管（存储于中华人民共和国境内）

  - **Apple App Store / Google Play**：处理应用内支付，我们不收集您的支付卡信息
- **业务变更**：合并、收购或重组时，依法告知并继续受本政策约束

其中 RevenueCat 等服务提供商可能涉及在境外处理上述信息。我们将依法采取必要措施（如告知、同意、合同约束等）保障您的个人信息权益。

## 5. 信息存储与保留

- 您创建的内容默认优先保存在您的本地设备；除非您主动启用云同步或备份功能，我们不会主动上传全部本地文件
- 我们仅在实现本政策所述目的所必需的期限内保留信息；期满后将删除或匿名化处理
- 信息原则上存储于中华人民共和国境内；如需跨境传输，我们将依法履行评估、告知与同意等义务

## 6. 信息安全

我们采取合理的技术与管理措施保护您的信息，例如访问控制、传输加密（如适用）、最小权限原则等。尽管我们努力保障安全，互联网环境并非绝对安全，请您妥善保管设备及账户信息。

## 7. 您的权利

根据适用法律法规（包括《个人信息保护法》），您享有以下权利：

- **查阅、复制**您的个人信息
- **更正、补充**不准确或不完整的信息
- **删除**相关信息（在符合法定条件时）
- **撤回同意**（不影响撤回前基于同意进行的处理）
- **注销账户**（在 App 内删除账号，流程见第 8 节）
- **获取解释**本政策或个人信息的处理规则

除注销账户需在 App 内办理（见第 8 节）外，您可通过 **admin@shadowstitch.cn** 行使上述其它权利。我们将在验证身份后于合理期限内答复。

## 8. 账号注销

您可以在 App 内注销（删除）账号。注销一经完成即永久生效，且不可恢复。

### 8.1 删除账号

- **入口**：打开 App → 设置 → 账号 → 「删除账号」。
- **处理结果**：账号、资料、积分、邀请记录与云端纸样备份将被永久删除；已购积分与订阅权益将作废且不退费；本机纸样库默认保留。
- **可选**：可勾选「一并删除本机纸样文件」，同时清除设备上的本地纸样文件。
- **确认**：系统会要求二次确认（「最后确认」）。确认后立即执行删除，此操作不可撤销。
- **Apple 登录用户**：使用 Sign in with Apple 登录的，删除账号时会同时向 Apple 撤销授权并删除相关登录数据。

### 8.2 删除游客数据

若您未登录而以游客身份使用 App，可在 设置 → 账号 → 「删除游客数据」清除本机游客数据。

## 9. 未成年人保护

我们的服务主要面向成年人。若您未满 18 周岁，请在监护人指导下阅读本政策并使用服务。我们不会主动面向未成年人收集超出必要范围的个人信息。

## 10. 政策更新

我们可能适时更新本政策。重大变更时，我们会通过 App 内提示、网站公告或其他合理方式通知您。更新后继续使用服务，即视为您接受修订后的政策。
